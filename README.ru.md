# Pi Polyglot

Расширения для [Pi](https://pi.dev) на любом языке через **stdio**, **HTTP + SSE** или **gRPC**.

Один TypeScript-адаптер загружается в Pi. Остальные расширения — отдельные программы или сетевые сервисы. SDK Pi им не нужен: достаточно реализовать [протокол](docs/protocol.md). Для gRPC нужны обычные библиотеки gRPC/Protobuf вашего языка.

Это экспериментальная версия **0.2**, проверенная с **Pi 1.5.2**. Она не обещает полную совместимость со всем TypeScript API Pi. Это не MCP и не протокол расширений Octet.

## Что поддерживается

- Инструменты с JSON Schema и текстовыми результатами.
- Slash-команды с отдельным пространством имён.
- Хуки `session_start`, `before_agent_start`, `tool_call`.
- Прогресс, таймауты и кооперативная отмена.
- Обратные запросы к Pi: уведомления и подтверждения пользователя.
- Три транспорта с одним общим контрактом.
- Примеры на Python, Go, TypeScript и Rust — каждый поддерживает все три транспорта.

Добавлен **гибридный TUI**: произвольные безопасные текстовые кадры можно смешивать с локальными полями ввода, списками, кнопками, таблицами и деревьями. Выполнение произвольного JavaScript-компонента, плагины провайдеров, динамические каталоги инструментов, автоматическая передача файлов и восстановление операций после обрыва связи не поддерживаются.

## Быстрый запуск

Нужны Node.js 22+, npm и установленный Pi 1.5.2.

```sh
git clone https://github.com/whiterabbit1983/pi-polyglot.git
cd pi-polyglot
npm ci

PI_POLYGLOT_CONFIG="$PWD/examples/configs/stdio.json" \
  pi -e ./src/index.ts
```

В Pi:

```text
/pg_demo_hello читатель
```

Попросите модель вызвать `pg_demo_greet` с аргументом `name`. Пример запросит подтверждение через интерфейс Pi. Инструмент `pg_demo_wait` принимает `milliseconds` и показывает работу прогресса/отмены.

Slash-команда не требует обращения к модели. Для использования инструментов моделью нужна обычная настройка провайдера Pi.

## Гибридный TUI

Запустите Pi в обычном интерактивном терминале:

```sh
PI_POLYGLOT_CONFIG="$PWD/examples/configs/tui-stdio.json" \
  pi -e ./src/index.ts
```

Выполните по очереди:

```text
/pg_demo_ui_form
/pg_demo_ui_counter
```

**Форма:** текстовый кадр от расширения + локальное поле имени, выбор окружения и кнопка. Tab/Shift-Tab переключают фокус, стрелки меняют выбор, Enter на кнопке отправляет результат. Ввод и отправка формы работают без ожидания сети.

**Счётчик:** расширение рисует кадры на своём языке. Стрелки вверх/вниз меняют значение, Enter завершает взаимодействие. Escape всегда закрывает экран локально.

Для сети есть конфигурации `tui-http.json` и `tui-grpc.json`. Все четыре языка поддерживают оба примера UI. Нужны явное разрешение `ui.custom` и согласование возможности `tui_v1`. Базовый протокол остаётся версии 0.1; обычные старые расширения продолжают работать без этих полей.

UI доступен **только из команды и только в терминальном режиме Pi**. RPC/print/headless получают явную ошибку. Таймаут взаимодействия `uiTimeoutMs` по умолчанию — 5 минут; отмена, разрыв связи и перезагрузка закрывают экран. Одновременно может быть открыт один custom UI этого адаптера.

Кадры используют текст и безопасные стили, не произвольные ANSI-команды. Обновления сохраняют локальные правки и фокус. Мышь, многострочный редактор, постоянные виджеты и запуск готовых curses/Bubble Tea-приложений не реализованы. [Спецификация UI](docs/tui-protocol.md).

Каждый пример содержит каталог инструментов и обработчики. Чтобы добавить свою функцию, дополните каталог и ветку обработки `tool.call`; менять транспорт не нужно. Примеры специально реализованы независимо, кроме TS, который использует общие RPC/framing-помощники этого проекта.

Для HTTP выберите `examples/configs/http.json`, для gRPC — `examples/configs/grpc.json`. Сначала запустите сетевой пример, затем Pi. Обоим процессам передайте одинаковый `POLYGLOT_TOKEN` через окружение. Подробнее — в [основном README](README.md).

## Проверки

```sh
npm run typecheck
npm test
npm run test:matrix -- typescript
npm run test:pi
```

После сборки остальных примеров по их инструкциям:

```sh
npm run test:matrix
npm run test:ui
npm run test:tui
```

Первые две команды проверяют все 12 комбинаций без UI и с UI. `test:tui` запускает настоящий интерактивный Pi через POSIX PTY и проверяет форму, счётчик, клавиатуру, изменение размеров и Escape без запроса к модели. Проверка `test:pi` запускает настоящий Pi в изолированной временной конфигурации, без запроса к модели. [Результаты и границы проверки](docs/verification.md).

## Безопасность

Конфигурация включается явно через `PI_POLYGLOT_CONFIG`; без неё ничего не запускается. Разрешения на UI и хуки задаются отдельно. При ошибке загрузки выбранной конфигурации адаптер блокирует вызовы инструментов, а не молча отключает политику.

Локальный процесс наследует права и окружение Pi: это **не песочница**. Удалённому сервису передаются только данные выбранных операций, однако разрешённые хуки могут раскрыть промпты и аргументы инструментов. Сетевые примеры слушают только loopback; для удалённого развёртывания нужны TLS и защищённая конфигурация сервиса.
